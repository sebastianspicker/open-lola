# Legal Notes

This document is a project boundary note, not legal advice.

## Original LoLa Licensing Check

The original LoLa software is developed by Conservatorio di Musica G. Tartini from Trieste, Italy, in collaboration with GARR.

The official LoLa website states that LoLa is licensed software, free for academic and education non-profit uses, and shareware in other cases. It also states that users receive a license code and restricted-area download credentials after sending a filled and signed license to the LoLa project contact.

The LoLa 2.0.0 manual identifies the manual and software documentation as copyright 2005-2019 by Conservatorio di musica G. Tartini.

Sources checked:

- <https://lola.conts.it/>
- <https://lola.conts.it/downloads/Lola_Manual_2.0.0_rev_001.pdf>

## Open LoLa Boundary

Open LoLa only publishes code and documentation written for this interoperability project. It does not publish or redistribute:

- original LoLa installers;
- original LoLa executables or DLLs;
- license keys or license forms;
- proprietary source code;
- binary patches;
- extracted resources;
- raw decompiler output;
- private packet captures or lab artifacts.

Users must obtain and run original LoLa under their own valid LoLa license from the official project.

## Educational Demonstration Use

This repository is intended for education, research, testing, documentation, and interoperability experiments. Demonstrations against Windows LoLa should be run only with licensed LoLa installations and in a use context permitted by the original LoLa license.

Commercial or non-academic use of original LoLa may require a shareware license or separate permission from the LoLa project.

## Interoperability And Reverse Engineering

The connector documents externally observable network behavior and includes independently written connector code. Interoperability and reverse-engineering rules vary by jurisdiction and by license terms. Contributors are responsible for making sure their work is lawful and does not include proprietary material.

Do not contribute copied decompiler output, proprietary LoLa code, binary assets, or private license material.

## Naming

"LoLa" refers to the original Low Latency Audio Visual Streaming System project. "Open LoLa" is an independent open-source connector and documentation project and is not affiliated with or endorsed by Conservatorio Tartini, GARR, or the original LoLa project.
