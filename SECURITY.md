# Security

Open LoLa is experimental interoperability software. Do not expose test connectors to untrusted networks.

For security-sensitive reports, avoid posting packet captures or institution details publicly. Open a private disclosure path with the repository maintainers once one is available on GitHub.

When sharing captures or logs, scrub:

- public IP addresses;
- institution names;
- user names;
- hostnames;
- license keys;
- LoLa restricted-area credentials.
