## Scope

This report validates the M06 source-level drift and packet-loss concealment
harness: fixed-target jitter handling, packet-age telemetry, outside-callback
drift estimation, bounded correction events, drift/PLC report schema,
same-deadline PLC invariants, fixture validation, synthetic smoke output, and
the G05 fixed-target certification wrapper. It does not validate a real
60-minute fixed-target route run.

## Drift And PLC Contract

The report records:

- route and UDP PCM packet mode;
- sender frame index, receiver playout frame index, packet age, and drift in
  frames;
- fixed-target jitter-buffer decisions for queued, late, duplicate, and
  capacity-limited packets;
- same-deadline PLC events with missing sequence number, policy, target depth
  before/after, branch-bounded status, and retransmission-wait flag;
- drift correction events with execution location and target-growth frames;
- callback p99/max, underruns, drift slope, max absolute drift, event counts,
  artifact assessment status, and verdict.

PASS reports require a 60-minute run, zero underruns, completed artifact
assessment, no hidden playout growth, no target-depth increase, no wait for
retransmission, and no unbounded correction inside the callback.

G05 certification PASS additionally requires measured mode, an accepted F02
realtime-engine source report, an accepted G04 route certification, a PASS
drift/PLC report, packet-mode and route identity parity, a measured
same-hardware LoLa baseline comparison, a LoLa-class-or-faster result, a run
artifact path, and no placeholder or fixture evidence.
