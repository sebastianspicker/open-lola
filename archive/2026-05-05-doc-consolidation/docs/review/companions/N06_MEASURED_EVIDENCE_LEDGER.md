## Objective

Create a ledger that separates synthetic smokes and source-level validators
from real measured hardware, route, signing, clean-Mac, and benchmark evidence.

- `mac-port/reports/`
- `docs/benchmarks/`
- `docs/compliance/final-review-packet.md`
- `docs/compliance/release-readiness-checklist-run.md`

- source validators and synthetic smoke commands

## Evidence Classes

| Class | Meaning | PASS eligibility |
|---|---|---|
| Synthetic smoke | Generated by local source code without real target hardware. | No release/runtime PASS by itself. |
| Source validator | Checks schema, guards, and report shape. | No release/runtime PASS by itself. |
| Measured local evidence | Captured on actual target hardware/route. | Possible, if complete. |
| Clean-Mac evidence | Validated on a clean target Mac with package/signing state. | Required for release PASS. |
| External/witnessed evidence | Independently captured or reproduced measurement. | Strongest runtime proof. |

## Acceptance Criteria

- Every active report in `mac-port/reports/` is labeled by evidence class.
- Synthetic reports are not used to claim real hardware PASS.
- M15, P04, P05, and release hardening remain `PARTIAL` until real evidence is
  attached.
