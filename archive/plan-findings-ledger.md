## Open Questions Compared To Current State

This section consolidates project open questions against the current source and documentation state. It is updated as findings are remediated.

### Realtime Audio

1. Can started realtime audio graphs outlive their owner? Current state: addressed under `AUD-P0-AUDIO-001`; graph deinitialization now stops IOProcs before scratch buffers are released.
2. Does AV raw PCM RX reassemble fragments before playout? Current state: addressed under `AUD-P0-AUDIO-002`; raw OpenLoLa audio RX now carries persistent fragment reassembly state and queues only complete payloads.
3. Is cross-thread audio ring metadata synchronized without Swift array races? Current state: addressed under `AUD-P0-AUDIO-003`; ring slot metadata now uses fixed raw storage plus atomic occupancy state rather than Swift metadata arrays.

### Documentation And Release Contract

1. Is root `plan.md` allowed as an active authority document? Current state: addressed under `AUD-P0-PLAN-001`; the docs verifier now permits active root `plan.md` only when `plan-findings-ledger.md` and `plan-status.md` are present.

### Direct P2P Network And Control

1. Can manual direct-P2P runs advertise wildcard endpoints? Current state: addressed under `AUD-P1-NET-001`; manual direct runs now reject wildcard advertised hosts before socket bind.
2. Are manual direct-P2P active ports validated consistently? Current state: addressed under `AUD-P1-NET-002`; a shared manual port set now validates control/audio/video/metrics and same-host remote-control uniqueness before runtime bind.
3. Can the two-peer supervisor overstate PASS evidence? Current state: addressed under `AUD-P1-NET-006`; supervisor PASS now requires aggregate report generation plus collected child reports and RX proofs.
4. Does the wired metrics transport exchange peer metrics? Current state: addressed under `AUD-P1-NET-007`; runners now publish metrics packets on the metrics transport and store remote metrics from both control and metrics packets.

### Video Runtime

1. Can unsafe raw video packetization start silently? Current state: addressed under `AUD-P1-VIDEO-001`; raw AV runs now estimate fragments before start and reject shapes over the active profile budget.
2. Does live video RX use the AV sync policy model? Current state: addressed under `AUD-P1-VIDEO-002`; video RX now routes decisions through `AVTimestampAligner` and records aligned/deferred/dropped counters.
3. Does AES67 audio sync compare local receive time to remote video timestamps? Current state: addressed under `AUD-P1-VIDEO-003`; AES67 RTP timestamps now map through an explicit host-time anchor before updating the playout anchor.
4. Does AVFoundation capture timestamp callback arrival instead of media presentation? Current state: addressed under `AUD-P1-VIDEO-007`; sample-buffer presentation timestamps now drive captured frame timestamps and callback arrivals are retained separately.
